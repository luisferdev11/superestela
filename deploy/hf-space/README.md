# SuperEstela

Demo del hackathon Diablos Rojos × ISAC: cómo cambia el valor de un lanzador al pasar del nivel del
mar a la altitud extrema.

El acceso es con usuario y contraseña. Los datos son de ISAC y del club: se presentan resultados, no
los datos. Prohibido usarlo para apuestas.
